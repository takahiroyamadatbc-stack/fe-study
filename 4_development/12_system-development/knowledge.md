# システム開発技術の知識

## 試験で問われるポイント

1. [FE/AP] ホワイトボックス＝内部構造、ブラックボックス＝入力と出力
2. [FE/AP] 同値分割・境界値分析はブラックボックスの手法
3. [FE/AP] 多相性はオーバーライド（再定義）で実現する

## 詳細

### ホワイトボックステストとブラックボックステスト [FE/AP]

| 項目 | ホワイトボックス | ブラックボックス |
|---|---|---|
| 注目点 | 内部構造（分岐・ループ） | 入力と出力の関係（仕様） |
| 主な手法 | 命令網羅、判定条件網羅、条件網羅 | 同値分割、境界値分析 |
| 主な場面 | 単体テスト | 単体〜システムテスト |

- 見分け方：「内部構造」「網羅」→ホワイト。「入力と出力」「同値」「境界値」→ブラック
- 「プログラムの機能」に注目するのは、システムテスト（システム適格性確認テスト）

### オブジェクト指向の基本用語 [FE/AP]

| 用語 | 意味 |
|---|---|
| カプセル化 | データと操作をまとめ、中身を隠す |
| 継承 | 上位クラスの性質を下位クラスが引き継ぐ |
| 多重継承 | 複数の上位クラスから継承する |
| オーバーライド | 上位クラスのメソッドを下位クラスで再定義する |
| 多相性 | 同じメッセージでもオブジェクトごとに動作が変わる |
| メッセージパッシング | オブジェクトにメッセージを送って処理を頼む |

- 多相性（ポリモーフィズム）を実現する仕組みが**オーバーライド**
- 多重継承は継承の「形」の話で、多相性に特有のものではない
