# オブジェクト指向の知識

## 試験で問われるポイント

1. [FE/AP] 多相性はオーバーライド（再定義）で実現する
2. [FE/AP] カプセル化＝データと操作をまとめて中身を隠す
3. [FE/AP] 多重継承は継承の「形」で、多相性に特有ではない

## 詳細

### 基本用語 [FE/AP]

| 用語 | 意味 |
|---|---|
| カプセル化 | データと操作をまとめ、中身を隠す |
| 継承 | 上位クラスの性質を下位クラスが引き継ぐ |
| 多重継承 | 複数の上位クラスから継承する |
| オーバーライド | 上位クラスのメソッドを下位クラスで再定義する |
| 多相性 | 同じメッセージでもオブジェクトごとに動作が変わる |
| メッセージパッシング | オブジェクトにメッセージを送って処理を頼む |

- 多相性（ポリモーフィズム）を実現する仕組みが**オーバーライド**
- 「多」という字につられて多重継承を選ばない
