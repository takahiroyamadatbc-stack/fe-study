## 問題

マルチプロセッサ環境で動作するOSの特徴に関する記述のうち，適切なものはどれか。

- ア：疎結合マルチプロセッサシステムでは，主記憶とデータを共有する。
- イ：疎結合マルチプロセッサシステムでは，主記憶に存在する物理的に一つのOSによって制御される。
- ウ：密結合マルチプロセッサシステムでは，各タスクはどのプロセッサでも実行できるので，タスク間で同期をとる機能が必要になる。
- エ：密結合マルチプロセッサシステムでは，主にジョブやトランザクションなどの一まとまりの仕事の単位で負荷配分が行われる。

## 答え

- 正解：**ウ**
- 自分の回答：覚えていない

## 解説

- **密結合**：複数のCPU（Central Processing Unit）が**1つのOS（Operating System）と主記憶を共有**する
- **疎結合**：コンピュータごとに**OSと主記憶を持ち**、通信で結ぶ（クラスタ）

- ア：× 疎結合は主記憶をそれぞれ持つ（共有するのは密結合）
- イ：× 疎結合はOSもそれぞれ持つ（1つのOSは密結合）
- ウ：○ 密結合はどのCPUでもタスクを実行できるため、タスク間の同期が必要
- エ：× ジョブ・トランザクション単位で負荷を配分するのは疎結合。密結合はもっと細かい単位で分散する

## 次に同じ問題が出たら

- 「共有・1つのOS」→密結合、「それぞれ持つ・ジョブ単位」→疎結合
