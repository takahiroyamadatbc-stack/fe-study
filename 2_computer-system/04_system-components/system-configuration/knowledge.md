# システムの構成方式の知識

## 試験で問われるポイント

1. [FE] 密結合＝1つのOSと主記憶を共有、疎結合＝それぞれ持つ
2. [FE] 密結合はタスク単位、疎結合はジョブ・トランザクション単位で負荷を分散
3. [FE] 疎結合マルチプロセッサはクラスタとも呼ばれる

## 詳細

### マルチプロセッサ：密結合と疎結合 [FE]

**マルチプロセッサ**は、複数のCPU（プロセッサ）で処理を分担する構成。CPUどうしの「つながりの強さ」で2種類に分かれる。

- **密結合（tightly coupled）**：1台のコンピュータの中に複数のCPUがあり、**主記憶とOSを共有**する構成。CPUどうしが同じメモリを直接読み書きするので、つながりが「密」。今のPCやサーバのマルチコアCPUがこれに近い
- **疎結合（loosely coupled）**：主記憶とOSを**それぞれ持つ複数のコンピュータ**を、ネットワークなどの通信でつないだ構成。やり取りは通信経由なので、つながりが「疎（ゆるい）」。**クラスタ**とも呼ばれる
- イメージ：密結合は「1つの机（主記憶）を複数人で囲んで作業する」。疎結合は「それぞれ自分の机を持ち、電話（通信）で連絡し合う」

| 項目 | 密結合 | 疎結合 |
|---|---|---|
| OS | 1つを共有 | コンピュータごとに持つ |
| 主記憶 | 共有 | コンピュータごとに持つ |
| 負荷分散の単位 | タスク（細かい） | ジョブ・トランザクション |

- 密結合は、どのCPUでもタスクを実行できるため、**タスク間の同期**をとる機能が必要
- 疎結合は、複数のコンピュータを高速な通信で結んだもの（**クラスタ**）
