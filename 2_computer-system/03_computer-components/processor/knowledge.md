# プロセッサの知識

## 試験で問われるポイント

1. [FE] CPU（Central Processing Unit：中央処理装置）は制御装置（命令を解読して指示）と演算装置（計算）に分かれる
2. [FE] 命令レジスタ・命令デコーダ・プログラムカウンタは制御装置側
3. [FE] ALU（Arithmetic Logic Unit：算術論理演算装置）・アキュムレータは演算装置側

## 詳細

### CPUの構成要素 [FE]

| 部品 | 分類 | 役割 |
|---|---|---|
| プログラムカウンタ | 制御 | 次に実行する命令のアドレスを持つ |
| 命令レジスタ | 制御 | 主記憶から読んだ命令を入れておく |
| 命令デコーダ | 制御 | 命令を解読し、各装置への制御信号を作る |
| ALU | 演算 | 算術演算・論理演算を行う |
| アキュムレータ | 演算 | 演算の途中結果を置く |
| メモリアドレスレジスタ | 主記憶とのやり取り | アクセスする主記憶のアドレスを持つ |

- 見分け方：名前に「命令」が付く部品は制御装置。「演算」「途中結果」は演算装置
