# LANの基礎の知識

## 試験で問われるポイント

1. [FE/AP] 宛先の範囲：ユニキャスト（1台）、マルチキャスト（選ばれた複数）、ブロードキャスト（全員）
2. [FE/AP] どれも「1回の送信」で届ける。順番に送るわけではない
3. [FE/AP] CSMA/CD は、衝突を検出したら待って送り直す方式

## 詳細

### 宛先による送信方式 [FE/AP]

| 方式 | 宛先 | 例 |
|---|---|---|
| ユニキャスト | 特定の1台 | 普通の通信 |
| マルチキャスト | 選ばれた複数のノード | 動画の同時配信 |
| ブロードキャスト | 同一セグメントの全ノード | ARPの問い合わせ |

- ブロードキャストの宛先IPアドレスは、**ホスト部のビットがすべて1**

### CSMA/CD [FE/AP]

- 送信前に回線が空いているかを確認し（CS）、複数の端末が共有し（MA）、衝突を検出したら（CD）時間をおいて送り直す
- 有線LAN（イーサネット）の方式。無線LANは衝突を**避ける** CSMA/CA
