# LANの基礎の知識

## 試験で問われるポイント

1. [FE] 宛先の範囲：ユニキャスト（1台）、マルチキャスト（選ばれた複数）、ブロードキャスト（全員）
2. [FE] CSMA/CD は有線LANで、衝突を**検出**したら待って送り直す。無線LANの CSMA/CA は衝突を**回避**する
3. [FE] ブロードキャストアドレスは、IPアドレスのホスト部をすべて1にしたもの

## 詳細

### 宛先による送信方式 [FE]

| 方式 | 宛先 | 例 |
|---|---|---|
| ユニキャスト | 特定の1台 | 普通の通信 |
| マルチキャスト | 選ばれた複数のノード | 動画の同時配信 |
| ブロードキャスト | 同一セグメントの全ノード | ARPの問い合わせ |

- どれも**1回の送信**で届ける。1台ずつ順番に送るわけではない
- ARP（Address Resolution Protocol：アドレス解決プロトコル）は、IPアドレスから相手のMACアドレス（Media Access Control address：機器ごとの固有番号）を調べる仕組み。「このIPアドレスの人は誰？」を全員に聞くので、ブロードキャストを使う

### ブロードキャストアドレス [FE]

IPアドレス（Internet Protocol address）は「ネットワーク部」と「ホスト部」に分かれる。**ホスト部のビットをすべて1**にしたアドレスが、そのネットワーク全体への宛先（ブロードキャストアドレス）になる。

**例1：192.168.1.0/24**

- 「/24」＝先頭24ビットがネットワーク部。残り8ビット（最後の数字）がホスト部
- ホスト部8ビットをすべて1にする：11111111（2進数）＝ 255
- ブロードキャストアドレスは **192.168.1.255**

**例2：192.168.1.64/26**

- 「/26」＝先頭26ビットがネットワーク部。ホスト部は残り6ビット
- 最後の数字 64 を2進数にすると 01000000。先頭2ビット「01」はネットワーク部
- ホスト部6ビットをすべて1にする：01**111111** ＝ 127
- ブロードキャストアドレスは **192.168.1.127**

| ホスト部 | 意味 | 例1（/24） |
|---|---|---|
| すべて0 | ネットワークアドレス（ネットワーク自体） | 192.168.1.0 |
| すべて1 | ブロードキャストアドレス | 192.168.1.255 |
| それ以外 | 各機器に割り当てられる | .1〜.254（254台） |

- ホスト部の0と1の組み合わせのうち、「すべて0」と「すべて1」は機器に使えない。割り当てられる台数が「2ⁿ−2」になるのはこのため

### CSMA/CD [FE]

**CSMA/CD（Carrier Sense Multiple Access with Collision Detection：搬送波感知多重アクセス／衝突検出）**は、1本の回線を複数の端末で共有する有線LAN（Local Area Network：構内ネットワーク）で、送信がぶつからないように調整する方式。昔のイーサネット（Ethernet）で使われた。

名前の4つの部分が、そのまま動きを表している。

| 略語 | 元の言葉 | 意味 |
|---|---|---|
| CS | Carrier Sense（搬送波感知） | 送信前に、回線に信号が流れていないか確認する |
| MA | Multiple Access（多重アクセス） | 複数の端末が同じ回線を共有し、誰でも送信できる |
| CD | Collision Detection（衝突検出） | 同時に送信してぶつかったら、それを検出する |

**送信の流れ**

1. 回線が空いているか確認する（CS）
2. 空いていれば送信する（MA）
3. 他の端末とたまたま同時に送信してデータが衝突したら、それを検出する（CD）
4. ジャム信号を流して、衝突が起きたことを全員に知らせる
5. **ランダムな時間**待ってから送り直す（全員が同じ時間待つと、また衝突するため）

**特徴**

- 端末や通信量が増えると衝突が増え、効率が落ちる
- 今のLANは、スイッチングハブと全二重通信（送信と受信を同時に行う）が主流で、そもそも衝突が起きないため、CSMA/CD はほぼ使われていない。それでも試験には出る

### CSMA/CD と CSMA/CA [FE]

| 項目 | CSMA/CD | CSMA/CA |
|---|---|---|
| 最後の2文字 | Collision Detection（衝突**検出**） | Collision Avoidance（衝突**回避**） |
| 使う場所 | 有線LAN | 無線LAN |
| 考え方 | ぶつかったら検出して送り直す | ぶつからないよう、送信前にランダムな時間待つ |

- 無線では、自分が送信している間に衝突を検出できない。そのため、最初から衝突を避ける CSMA/CA を使う
- 覚え方：**D**＝**D**etection（検出）は有線、**A**＝**A**voidance（回避）は無線
